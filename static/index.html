Nhan dien cam xuc & ban tay - Web demo

Bản demo chạy trên trình duyệt của project Face Recognition (Python + OpenCV + DeepFace + MediaPipe). Webcam được lấy trực tiếp từ trình duyệt của bạn, mỗi frame được gửi lên server xử lý rồi trả về hiển thị.

Chua bat dau.

Lưu ý: xử lý qua server (không chạy trong trình duyệt) nên có độ trễ vài trăm ms đến 1-2 giây, tuỳ tốc độ server. Đây là bản demo cho mục đích học tập/portfolio.
